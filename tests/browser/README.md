# Browser regression fixtures

Recorded public responses from the preserved October 27, 2026 release. These are browser presentation/request tests, not fresh source qualification or accuracy evidence. Calculation operands are omitted from the fixture's expandable qualification report to reduce size; full financial fields and saved correction notes are retained. The API is intercepted locally. Scenario responses are stubbed so tests can observe request precision, restore and stale-result behavior; model mathematics is tested in the backend. No external API, AI request, correction or publication is allowed by the test server.
